Announcements

Manage timed announcements. Set ANNOUNCEMENTS and ANNOUNCEMENT_INTERVAL_MS in .env and restart bot.

Note: To enable announcements, update your .env with:
ANNOUNCEMENTS=Message1|Message2|Message3
ANNOUNCEMENT_INTERVAL_MS=900000 (15 minutes)
Then restart the bot.

OBS Overlays Configuration

Configure overlay URLs and settings for easy setup in OBS. Copy the URLs below and add them as browser sources in OBS Studio.

Alerts Overlay

Displays follow, subscription, bits, raid, and redemption alerts with animations and sounds.

Recent Events Overlay

Displays a scrollable list of recent follows, subscriptions, bits, raids, and redemptions.

Chat Box Overlay

Displays live chat messages with user roles and colors.

Goal Bar Overlay

Displays a progress bar for follower or subscriber goals.

How to Add to OBS

  1. Open OBS Studio
  2. Click the + button in the Sources panel
  3. Select Browser
  4. Give it a name (e.g., "Alerts")
  5. Copy the URL from above and paste it in the URL field
  6. Set the width and height (recommended sizes shown above)
  7. Make sure Refresh browser when scene becomes active is unchecked
  8. Click OK
